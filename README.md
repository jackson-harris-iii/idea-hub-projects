# Idea Hub projects

A directory of community-built tools, prototypes and open-source repositories. Start at [Idea Hub Sac](https://ideahubsac.org), [join a future build session](https://ideahubsac.org/join), or [contribute to the shared software](https://github.com/jackson-harris-iii/idea-hub).

| Project | What to explore | Source / license status |
| --- | --- | --- |
| [Idea Hub](https://github.com/jackson-harris-iii/idea-hub) | Reusable community board, moderated participation and interest inbox | MIT for application code; see notices |
| [Idea Hub Sac](https://ideahubsac.org) | Sacramento's live community board | [Public source edition](https://github.com/jackson-harris-iii/ideahub-sac), MIT for application code; production data and third-party media excluded |
| [Glass Onion / Sac Spending Tracker](https://glassonion-sac.netlify.app/) | Community-built spending transparency prototype | Public demo; source, creator attribution and license awaiting confirmation |
| [Mercy Holistic Connect](https://mercy-holistic-connect.replit.app/) | Community-built resource connection prototype | Public demo; source, creator attribution and license awaiting confirmation |

A public website is not automatically open source. External projects remain with their creators. Listing a project does not imply ownership, endorsement, verified outcomes, or readiness for sensitive use.

## Add a project

Open an issue or pull request with its name, creator/maintainer, community need, demo URL, repository URL (if public), license, status (idea/prototype/pilot/maintained), last update and the help wanted. Include only public details and media you have permission to share. Use null or “not yet provided” for unknown source/license information.

## Maintain a project

Each project needs an identifiable maintainer, a feedback route and a statement of what works today. People can offer skills, resources or funding interest through the board. No payments are collected here and an offer is not a guaranteed commitment.

Jackson Harris is the initial directory maintainer. Anyone can propose a correction through a pull request. Organization ownership can be revisited as more maintainers and city communities join.
